# Grind

Personal workout log. Custom workouts, a bilingual library of 466 exercises (English and Ukrainian), sets prefilled from last time, a progression tip for every exercise, progress charts, body measurements and progress photos.

Live: https://spektoruk.github.io/grind/

## Use it on iPhone
Open the link in Safari, tap Share, then **Add to Home Screen**. It opens full screen and works offline.

## Data
Everything is stored on your device (browser storage, photos in IndexedDB). Nothing is sent anywhere and nothing syncs between devices. Use **Settings → Export JSON** for backups and **Import JSON** to move data.
